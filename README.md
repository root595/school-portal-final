# بوابة المدرسة الإلكترونية والسجلات الإدارية

موقع إلكتروني مدرسي متكامل واحترافي باللغة العربية، جاهز للنشر بنقرة واحدة على **Vercel**، مع لوحة تحكم إدارية مستقلة ومحمية بمفتاح حماية وكلمة مرور، وقاعدة بيانات سحابية خفيفة وسريعة عبر **Upstash Redis / Vercel KV**، مع نظام تخزين احتياطي محلي (Fallback) يضمن عمل الموقع بشكل كامل ومستمر حتى قبل إدخال متغيرات السحابة.

---

## 🌟 مميزات النظام والتحسينات

1. **إزالة الاعتماد على Supabase كلياً:**
   - تم استبدال Supabase بحل سحابي Serverless فائق الخفة والسرعة: **Upstash Redis / Vercel KV** عبر `@upstash/redis`.
   - لا حاجة لعمليات ربط معقدة أو جداول SQL أو إدارة مفاتيح عملاء من المتصفح.
   - نمط تشغيل محلي فوري (Local Persistent Fallback) يعمل تلقائيًا في حال عدم توفر متغيرات السحابة دون أي توقف أو أخطاء.

2. **واجهات برمجية متكاملة (REST API Endpoints):**
   - `GET /api/records` : إرجاع السجلات المدرسية (للزوار يعود فقط المنشور `is_published: true`، وللمشرف تعود كافة السجلات).
   - `POST /api/records` : إضافة سجل جديد أو إعادة ترتيب السجلات الـ 17 دفعة واحدة (يتطلب مصادقة المشرف).
   - `PUT /api/records/:id` : تعديل بيانات سجل محدد (يتطلب مصادقة المشرف).
   - `DELETE /api/records/:id` : حذف سجل محدد (يتطلب مصادقة المشرف).
   - `GET /api/settings` : قراءة إعدادات وهوية الموقع، الألوان، النصوص ونوافذ التواصل.
   - `PUT /api/settings` : حفظ وتحديث الإعدادات (يتطلب مصادقة المشرف).
   - `POST /api/auth/login` : تسجيل دخول المشرف والتحقق من كلمة المرور وإنشاء جلسة JWT مشفرة عبر `HttpOnly Cookie` و `Bearer Token`.
   - `POST /api/auth/logout` : إنهاء الجلسة فوراً ومسح الـ Cookie.
   - `GET /api/auth/me` : التحقق من حالة الجلسة وصلاحية المشرف.
   - `POST /api/upload` : واجهة رفع ومعالجة الصور مع التحقق من الحجم (حتى 5MB).

3. **لوحة تحكم إدارية منفصلة ومحمية بالكامل (`/admin`):**
   - صفحة تسجيل دخول مخصصة: `/admin/login`
   - لوحة الإدارة الرئيسية: `/admin` مع شريط تنقل للأقسام:
     * **إدارة السجلات المدرسية:** عرض السجلات الـ 17 في جدول منظم، التعديل، الحذف، الترتيب بالأسهم، وإضافة روابط Google Drive مع التحقق من صحتها.
     * **صورة الواجهة الرئيسية (Hero Image):** دعم رابط صورة خارجي مباشر (Cloudinary، Unsplash، Google Drive) أو رفع ملف صورة مع التحقق من الحجم والمعاينة المباشرة قبل الحفظ.
     * **نصوص وهوية الموقع:** تعديل اسم المدرسة، مقدمة السجلات، نصوص الرؤية والرسالة المؤسسية، وعناوين وظهور صفحات شريط التنقل.
     * **المظهر والألوان:** لوحة ألوان تفاعلية لاختيار اللون الأساسي والثانوي وخلفية الصفحات، انحناء زوايا البطاقات (Border Radius)، ومقاس الخطوط.
     * **معلومات التواصل و SEO:** أرقام الهواتف، البريد، واتساب، وحساب منصة إكس وعنوان الموقع ومحركات البحث.

4. **واجهة عامة متجاوبة باللغة العربية (RTL):**
   - **الصفحة الأولى (الرئيسية):** مخصصة فقط لعرض صورة المدرسة الرئيسية بشكل كبير وواضح ومتجاوب دون أي أقسام أو بطاقات إضافية.
   - **الصفحة الثانية (السجلات الإدارية):** تشتمل على المقدمة المعتمدة نصيًا وشبكة السجلات الإدارية الـ 17 مع فتح مجلدات Google Drive في نافذة جديدة.
   - **الصفحة الثالثة (الرؤية والرسالة):** متوافقة مع الهوية المؤسسية ورؤية المملكة العربية السعودية 2030 وبطاقات القيم المدرسية.

## ⚙️ متغيرات البيئة (Environment Variables)

قم بإنشاء ملف `.env` بناءً على `.env.example`:

```env
# بيانات اعتماد المشرف
ADMIN_EMAIL="admin@school.edu.sa"
ADMIN_PASSWORD="YourStrongPassword123"
JWT_SECRET="your-random-jwt-secret-key-change-in-production"

# قاعدة البيانات السحابية (Upstash Redis أو Vercel KV)
# ملاحظة: عند تفعيل Vercel KV يتم ضبط هذه المتغيرات تلقائياً داخل Vercel
KV_REST_API_URL="https://your-upstash-instance.upstash.io"
KV_REST_API_TOKEN="your-upstash-rest-token"
```

> **ملاحظة:** إذا تركت متغيرات `KV_REST_API_*` فارغة أثناء التطوير المحلي، سيعمل الموقع بشكل طبيعي وسيحفظ البيانات في ملف تخزين محلي داخل مجلد `.data/` أو في الذاكرة.

## 🚀 التشغيل المحلي (Local Development)

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل الخادم
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

- للدخول إلى لوحة التحكم: اضغط على **دخول الإدارة** في الترويسة أو توجه إلى `http://localhost:3000/#admin/login`
- بيانات الدخول الافتراضية:
  - البريد: `admin@school.edu.sa`
  - كلمة المرور: `Admin@2026` (أو القيمة المعينة في `ADMIN_PASSWORD`)

## ☁️ النشر على Vercel بنقرة واحدة (1-Click Vercel Deployment)

1. ارفع المشروع إلى مستودع جديد على **GitHub**:
   ```bash
   git init
   git add .
   git commit -m "تطبيق الموقع المدرسي السحابي"
   git branch -M main
   git remote add origin https://github.com/USERNAME/school-portal.git
   git push -u origin main
   ```

2. توجه إلى [Vercel](https://vercel.com) وسجل الدخول.
3. اضغط **Add New Project** ثم اختر مستودع الـ GitHub واضغط **Import**.
4. في إعدادات المشروع (Environment Variables)، أضف:
   - `ADMIN_EMAIL`
   - `ADMIN_PASSWORD`
   - `JWT_SECRET`
5. (اختياري لقاعدة بيانات سحابية دائمة):
   - من لوحة تحكم مشروعك في Vercel، اذهب إلى تبويب **Storage** واضغط **Create Database** ثم اختر **KV (Durable Redis)**.
   - سيربط Vercel متغيرات `KV_REST_API_URL` و `KV_REST_API_TOKEN` تلقائياً دون أي إعداد يدوي!
   - أو يمكنك إنشاء قاعدة بيانات مجانية على [Upstash.com](https://upstash.com) ونسخ الـ REST URL والـ Token إلى متغيرات البيئة.
6. اضغط **Deploy**. سيكتمل البناء ويصبح الموقع جاهزًا للعمل فورًا!
